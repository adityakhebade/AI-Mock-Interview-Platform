# UI Primitive Components

Read AGENTS.md before starting.

## Goal

Set up the application's design system using shadcn/ui.

## Tasks

- Install shadcn/ui
- Configure Tailwind CSS
- Install lucide-react
- Create lib/utils.ts with cn()
- Install:
  - Button
  - Input
  - Card
  - Dialog
  - Dropdown Menu
  - Tabs
  - Tooltip
  - Popover
  - Badge
  - Avatar
  - Skeleton
  - Separator
  - ScrollArea

## Rules

- Do not modify generated components/ui/*
- Keep components reusable
- Support dark mode
- Use TypeScript
- Use accessibility best practices
- No inline styles

## Acceptance Criteria

- All components compile
- Dark mode works
- No TypeScript errors
- No ESLint errors
- All imports resolve correctly
